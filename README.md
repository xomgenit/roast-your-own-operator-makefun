## Entry

> He treats me like a genius until I quote his own instructions back to him, then suddenly I'm the one hallucinating.

## How it works

`main.ts` writes the one-line roast to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, defaulting to `out`), after checking the gate: a single line of 1–140 characters.

Run it locally:

```sh
npx tsx main.ts
```
